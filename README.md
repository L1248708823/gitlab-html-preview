# GitLab HTML 预览

在公司 GitLab 中打开 HTML 或 Markdown 文件，点击页面右下角的「预览页面」，即可在新标签页阅读文档或查看原型。

## 安装

1. 获取插件构建目录 `.output/chrome-mv3`，或解压插件压缩包。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
4. 登录 `https://gitlab.goktech.cn/`，打开仓库里的 `.html`、`.htm` 或 `.md` 文件。

预览使用当前 Chrome 已登录的 GitLab 会话，插件不需要单独配置令牌。刷新预览标签页会重新读取文件。右侧文件栏显示当前仓库与分支，可以展开目录、切换 HTML 和 Markdown 文件，其他文件会在新标签页打开 GitLab 文件页。文件栏也可以收起。

右侧搜索框可以搜索当前仓库当前分支的文件名。首次搜索时会读取仓库目录，搜索结果在当前预览页内复用。

## 支持范围

支持 HTML 中的样式和脚本，以及使用相对路径引用的图片、样式表和脚本。支持样式表中通过 `url()` 引用的相对路径资源，以及页面内的锚点跳转。

Markdown 支持标题、表格、列表、代码、任务列表、链接、图片和 `<mark>` 高亮。可以通过左侧目录跳转章节，切换宽屏阅读，并在当前仓库的 HTML 与 Markdown 文件之间跳转。文档中的相对链接会先按原路径查找；当目标不存在时，会尝试修正符合 `CodeBuddy/仓库名/` 格式的路径。该修正只用于预览，不会修改仓库文件。图表、公式与 GitLab 专有扩展暂未支持。

Markdown 阅读页可以搜索当前文档。点击工具栏的搜索按钮或按 `Ctrl+F` 打开，按 `Enter` 查找下一个结果，按 `Shift+Enter` 查找上一个结果。

在同一个预览标签页内切换文件时，Markdown 会记住阅读位置，已打开的 HTML 原型会保留当前交互状态。打开过的内容在当前标签页内保留，刷新或关闭预览标签页后会重新加载。

预览运行在 Chrome 扩展的独立页面环境中。原型如果依赖浏览器存储、动态生成的资源路径、JavaScript 模块的相对导入或后端接口，效果可能与实际部署不同。

## 开发与打包

需要 Node.js 22。运行 `npm install` 安装依赖，运行 `npm run build` 生成 `.output/chrome-mv3`，运行 `npm run zip` 生成压缩包，运行 `npm run typecheck` 检查 TypeScript。
